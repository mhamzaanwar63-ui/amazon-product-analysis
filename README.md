# 🛒 Amazon India Product Analysis
## 📌 Project Overview
Analysis of Amazon India product listings using Excel.
Dataset contains 1,465 products across 9 categories.
## 🛠️ Tools Used
- Microsoft Excel
- Data Cleaning
- Formulas: COUNTIF, AVERAGEIF, SUMIF, VLOOKUP
## 📊 What I Analyzed
- Which category has most products
- Average rating per category
- Average discount per category
- Total savings per category
## 🔍 Key Findings
- Electronics has most products (526)
- HomeImprovement has highest discount (58%)
- Average rating across all categories: 4.1
